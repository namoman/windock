# Windock

Windows에서 열린 창을 작업표시줄에서 숨기고, 독 패널에서 다시 복원하는 보조 프로그램입니다.

## 기능

- **현재 창 보관**: `Ctrl+Shift+P` 또는 독 패널 버튼
- **작업표시줄 숨김**: Owner HWND 방식으로 창을 유지하면서 작업표시줄 버튼 제거
- **독 패널**: 보관한 창 목록 표시, 더블클릭으로 복원
- **창 선택 보관**: 열린 창 목록에서 직접 선택
- **시스템 트레이**: 백그라운드 상주, 독 표시/숨김
- **폴백**: 작업표시줄 숨김 실패 시 일반 최소화로 보관
- **HWND 갱신**: 2초마다 닫힌 창 자동 정리

## 빌드 및 실행

```powershell
cd d:\sw\dev\window
dotnet build
dotnet run --project WindowDock.App
```

## 프로젝트 구조

| 프로젝트 | 역할 |
|----------|------|
| `WindowDock.Core` | Win32 P/Invoke, 창 열거, Park/Restore 서비스 |
| `WindowDock.UI` | WPF 독 패널, 창 선택 대화상자 |
| `WindowDock.App` | 트레이 아이콘, 글로벌 핫키, 앱 진입점 |

## 사용법

1. 앱 실행 후 화면에 독 패널이 표시됩니다.
2. 정리할 창을 활성화한 뒤 `Ctrl+Shift+P`를 누릅니다.
3. 독 패널에서 항목을 더블클릭하면 이전 위치로 복원됩니다.
4. 트레이 아이콘에서 독 표시/숨김, 종료를 할 수 있습니다.

## 제한 사항

- 관리자 권한으로 실행된 창은 일반 권한에서 보관할 수 없습니다.
- 일부 앱은 parent 변경을 거부할 수 있으며, 이 경우 최소화로 폴백됩니다.
- UWP/Store 앱, 전체화면 게임은 지원이 제한될 수 있습니다.

## 설정 저장

보관 메타데이터는 `%AppData%\Windock\parked-windows.json`에 저장됩니다.
